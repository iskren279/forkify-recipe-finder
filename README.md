# Forkify Recipe Finder

A responsive recipe discovery application that allows users to search for recipes, view ingredients and cooking instructions, adjust serving sizes, bookmark favourites, and upload their own recipes.

## Live Demo

[View Forkify Recipe Finder](https://unique-cendol-a0eb87.netlify.app/)

## Features

- Search recipes by name or ingredient
- View detailed recipe information
- Adjust ingredient quantities based on servings
- Bookmark favourite recipes
- Upload custom recipes
- Responsive user interface

## Technologies Used

- JavaScript
- HTML5
- Sass (SCSS)
- Parcel
- REST API integration
- Git and GitHub
- Netlify
